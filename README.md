# A股复盘收割器（主板 · 二板定龙头专用）

盘后自动复盘工具：只看 **沪深主板** 当日 **收盘封板** 的股票，筛出 **2 连板** 的
晋级候选，按五维评分（题材/首板/二板/情绪/辨识）输出清单。

> **开源说明**：MIT 协议，**持续更新中**。仓库里只有程序系统，不含任何数据——
> 行情、涨停池、龙虎榜全部由免费公开接口在运行时获取；台账、模型、研究缓存由你
> 自己的运行逐日积累。文中的历史实测数字来自作者本机的归档，克隆后不会自带。

## 快速开始（克隆即用）

| 你的系统 | 步骤 |
|---|---|
| **Windows** | ① 安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 *Add python.exe to PATH*）<br>② `git clone https://github.com/Surri757/wall-street-dog.git`<br>③ 双击 **`work.bat`**：首次运行自动创建虚拟环境并装好全部依赖（几分钟，只有这一次），随后进入复盘菜单 |
| **macOS / Linux** | `git clone https://github.com/Surri757/wall-street-dog.git && cd wall-street-dog && python3 setup_env.py && .venv/bin/python work.py` |

- 依赖只有一份清单：[`requirements.txt`](requirements.txt)。实测环境 Windows + Python 3.11。
- **首次运行较慢**：全新环境实测约 8 分钟（首次安装依赖另需约 5 分钟；之后要从零拉日K并训练席位模型），之后每个交易日 1~2 分钟。
- 每个交易日 **15:05 之后**运行才是收盘数据；盘中运行得到的是预览，收盘后再跑会自动重拉。
- 想每天自动跑：Windows 双击 `setup_task.bat`，注册每交易日 15:10 的计划任务。
- 可选：有 NVIDIA 显卡可以另装 CUDA 版 PyTorch，席位模型的训练走 GPU；不装则用 CPU，功能与流程完全相同。
- 改了代码想自检：`python tests/test_logic.py`（全部离线，不联网）。

## 规则口径（2026-08 版）

| 项目 | 口径 |
|---|---|
| 股票范围 | 仅沪深主板：600/601/603/605、000/001/002/003 开头；ST 剔除；主板 ±10% |
| 候选池 | 曾涨停（含炸板）/ 曾跌停 / 振幅≥7% —— **仅用于情绪速览统计** |
| 参与判定 | 仅「收盘封板」股；**非封板股不拉日K、零网络直接跳过** |
| 2连板判定 | 优先东财涨停池连板数（lbc）；池缺失时日K近似（连续涨幅≥9.5%） |
| 涨停价 | 昨收×1.10 四舍五入到分（交易所口径） |
| **入池条件** | 收盘封板 + 2连板 + 五维评分 ≥60 |

### 五维评分（0~100）

| 维度 | 分值 | 构成 |
|---|---|---|
| A 题材地位 | 25 | **概念口径优先**：所属概念中最热板块的「涨幅+涨跌家数广度」10 + 是否概念领涨股 8（题材辨识度核心）+ 板块K线加速度 7（今日涨幅≥前4日均×1.5 = 加速）。概念接口不可用时**自动回退行业口径**：涨停家数10 + 板内身位8 + 题材发酵度7（同行业今日 vs 昨日涨停家数） |
| B 首板质量 | 25 | **真实昨日口径**（昨日涨停池重建）：封板时间8（<10:00 早）+ 实体板6 + 昨换手 5~25%（5）+ **昨日封成比6**（≥2倍=首板封单强） |
| C 二板强度 | 25 | 准一字开盘10（数据重校：晋级率58.8%远超高开优档）+ 缩量换手8 / 高开3-7% 7 / 充分换手6（>30% 死亡换手3）+ 炸板次数7 |
| D 情绪环境 | 15 | 炸板率4 + 晋级率4 + 赚钱效应4 + **情绪周期阶段3**（`mood.py` 多日序列判定六阶段：高潮/发酵3、回暖2、分歧1、冰点/退潮0；15日实证：高潮+3.85%/红盘66% vs 分歧+0.92% vs 冰点-5.67%） |
| E 辨识度 | 10 | 流通市值6（**<30亿最优**，调研：小盘打板收益显著更高）+ 股价4（<5元深低价/<10元低价） |

- **数据缺失惩罚**：每缺一项 -2 分（`BOARD_MISS_PENALTY`）。数据全盲的票中性分拿不满
  60，惩罚后更不可能混过线；board_note 会标注「缺失N项」。实测今日池拉取失败时，
  2板股分数自动压缩到 60 档并明确标注，不会虚高。
- **辨识度标签**：流通市值（小盘/中盘）、低价/深低价、封成比 —— 已计入 E 维评分。
- **封成比** = 收盘封单额/成交额（CSV 字段）。语料口径：封单量/成交量 >10 倍 → 次日涨停
  开盘概率 ~70%；3~10 倍 → 高开 6~10%。

### 评分校准锚点（公开统计基础比率）

评分标签为「概率参考」，真实校准依赖 `out/archive/` 积累的前向收益统计：

| 指标 | 基础比率 | 含义 |
|---|---|---|
| 一进二（首板→2板） | ≈15.7% | 大多数首板是一日游 |
| 二进三（2板→3板） | ≈34.7% | **本工具的基本盘：评分≥60 应显著高于 35%** |
| 连板晋级率 | 50-60%高涨 / 30-40%中性 / 15-25%冰点 | 情绪温度计（进情绪速览） |
| 昨涨停今表现 | 常态 +2%~4%，<-2% 转弱 | 打板赚钱效应（进情绪速览） |
| 涨停换手 | <5%缩量板好 / >30%不追 | C 维换手分档依据 |

### 评分校准闭环（calibrate.py）

每日收盘后运行 `main.py` 自动归档信号 → 之后随时运行 `python calibrate.py`，
按分数桶（60-69 / 70-79 / 80+）统计**次日开盘溢价、次日收盘、红盘率、晋级率（次日封板）、
3日最大涨幅**，并与基础比率（二进三≈34.7%）对照：

- 评分≥60 桶的晋级率应显著高于 34.7%，且 80+ 桶应单调高于 60-69 桶；
- 不满足时说明五维权重或门槛需要校准——依据 `out/archive/_forward.csv` 明细定位
  区分度差的维度，调整 `config.py` 阈值。

前向数据缓存在 `out/archive/_forward.csv`（增量，`--refresh` 全部重拉）；
**前向行情拉取带降级链（东财 kline → 腾讯 fqkline），失败不缓存、下次自动重试**；
信号日之后至少需 1 个交易日才有前向数据（周六校准周五信号会提示待数据）。
`main.py`/`work` 每次收盘运行后若检测到可校准的历史信号，会自动打印校准提示。

**样本不够等积累？用回灌**：`python backfill.py` 用东财历史涨停/炸板池（免费接口
约保留最近 3 周）+ 腾讯日K重建过去交易日的评分并写入归档。注意回灌对非交易日查询
会「回声」最后交易日数据，因此交易日判定走交易日历；回灌口径缺赚钱效应（统一按缺失
计分）、A维走行业兜底，跨桶可比但绝对分比实跑低 2~4 分。

### 校准结论（2026-08-30，回灌 106 条已实现样本，两轮）

第一轮（调研口径打分）：收益单调 ✔，但 **60 分门槛无筛选力**（98% 过线）→ 门槛提至 70；
对晋级无超额（35.6% vs 基线 35.8%）。

第二轮维度级分析定位到 **C 维方向反了**（106 样本实证）：

| 特征 | n | 组内次日收% | 组外% | 组内晋级 |
|---|---|---|---|---|
| 准一字开盘 | 34 | +4.44 | +1.08 | **58.8%** |
| 换手<5%（缩量板） | 34 | +4.39 | +1.10 | 50.0% |
| 高开3-7%优（原满分档） | 33 | +0.23 | +3.03 | 18.2% |
| 换手5-20%（原健康档） | 62 | +1.37 | +3.27 | 32.3% |

→ **C 维重校**：准一字 3→10 分、缩量换手 4→8、高开优 10→7、充分换手 8→6。
同批样本复核：60-69 桶转负（-0.62%）、80+ 桶 +5.06%/晋级 50%、
**过线池晋级 44.2% vs 基线 35.8%（+8.4pp 超额出现）**、单调 ✔ 且斜率更陡。

⚠️ **过拟合警告**：以上为同窗口（8/10~8/27）样本内调参，**8/31 起新样本才是真正样本外检验**。
拟合窗口登记在 `config.CALIB_FIT_UNTIL`，`calibrate.py` 自动把之后的样本单独统计并判读：
**样本外「过线池晋级率 > 样本外基线」→ ✔ 通过；反之 → ✘ 提示回退本轮 C 维调整**。
另：低价 +2.68 / 小盘 +1.61（E维方向✓）、题材退潮 -2.21（A维✓）、数据缺失 -3.48（惩罚✓）、
首板早封基本无区分（暂不动）。

### ❌ 上述「+8.4pp 超额」已于 2026-09-09 复核推翻（保留原文供追溯）

详见 [docs/research_log.md](docs/research_log.md) **五S**。三点更正：

   **p=0.348**，Fisher **p=0.154**，95%CI **[−9.1pp, +25.8pp]**。且它本身是调权后的
   样本内数字。`_forward.csv` 全部 167 条有效样本只跨 **22 个独立交易日**，
   过线 vs 未过线晋级率 46.6% vs 17.2% 朴素 z=4.32，**按日聚类后 t=1.72（p≈0.10）**。
2. **C 维重校优化的是不可变现的目标**：`events.csv` 2999 事件 / 241 独立交易日按日聚类，

   准一字组次日 100% 排队买不到。

## 滚动缓存机制（按周滚动，周五锁定，周一清空）

- 每个交易日的数据+结果独立存 `out/cache/{date}.pkl`，重复运行直接复用
- **周一~周四**窗口 = 本周内最近 3 个交易日；**周五锁定**周末悬停；**周一清空**开新轮
- **盘中保护（双保险）**：① 交易日 09:15~15:05 拒绝新拉快照（实时接口此时是今日盘中
  数据，而复盘日期是 T-1，新拉会污染历史）；② 15:00 前存的当日缓存，15:05 后运行一律作废重拉
- **日K增量拼接**：滚动缓存保留昨日日K，当日只需快照自带 OHLCV 拼一根（**零网络**）；
  快照昨收与缓存末根收盘一致性校验（容差 max(1分,0.1%)），除权/送转/停牌/跨源漂移自动
  触发全量重拉。实测增量与全量结果逐位一致；新候选股照常全量拉取
- **空缺补齐 `--fill`**：缺失日用东财历史涨停/炸板池补录（跌停/振幅历史不可补，报告会注明）
- 手动清理范围之外的留档放 `out/archive/`，程序不清理

输出到 `out/` 目录：

## 效率与精度（实测）

- **零网络日K**：上一交易日缓存 + 今日快照增量拼接，225 只候选 0.1s 分析完毕、日K请求 0 次
  （增量与全量的指标/判定逐位一致，除权自动全量重拉兜底）
- **只拉需要的**：非封板股不参与判定，直接跳过不拉日K（78/225 只需日K）
- **成交量单位归一**：东财/腾讯=手、新浪=股（实测），新浪路径入库统一 /100
- **候选池向量化**：build_candidates numpy 向量判定 ~5ms（原逐行 ~2s）
- **停牌防护**：日K末根日期 ≠ 复盘日的股票直接跳过
- **池解析双格式** + 0 行解析大声告警；快照主机轮换兜底

## 已知限制

- 免费接口偶发限流/改版：核心只依赖快照+日K+涨停池；池失败自动中性分并标注缺失项数
- 历史补录只能重建涨停/炸板池，跌停/振幅统计在补录日会偏少（报告注明）
- 涨停价按「昨收×1.10 四舍五入到分」近似，与交易所逐笔判定可能有极个别边界差异
- 退市整理期、上市首日等特殊涨跌幅规则未单独处理
- CSV 代码列为纯文本，Excel 打开可能丢前导零；pandas 读取加 `dtype={"code": str}`
- **评分是「龙头识别强度」，不是买入概率，不得据它建仓**（2026-09-10 口径切换后实测，
  详见 [docs/research_log.md](docs/research_log.md) **五T** 与
  `out/research/snapshots/2026-09-10/`）：177 条有效样本 / **23 个独立交易日**，
  过线池(≥70) 可成交净收益 **−0.80%** vs 未过线 **−0.55%**，差 **−2.08%**、
  聚类 **t=−1.39 不显著**；而晋级率差 **+19.16pp、t=+2.03 显著**。
  即**识别龙头是真的，变现不了也是真的**。一字率随分数单调上升
  （60-69 桶 5% → 70-79 桶 32% → 80-100 桶 **55%**）：评分越高越买不到。
  门槛敏感性显示过线池绝对净收益随门槛升高单调恶化（−0.52%→−1.21%）、
  差值 t 在门槛 66 与 70 之间**翻号** → 门槛 70 已冻结，不再据校准数字微调。
  BH-FDR 校正后 28 个维度检验**无一 q<0.10**（最小 q=0.305）
- **样本外几乎为空**：OOS（>2026-08-27）仅 **9 个独立交易日**，配对日 7 < 门槛 8，
  校准器输出「簇数不足，既不能判通过也不能判回退」。全样本 +19.16pp 的信息优势
  在 OOS 只剩 +0.57pp（t=+0.03）——**8/30 那轮 C 维重校的超额几乎全在拟合窗口内**，
  该结论已在待检清单中撤销
- **信号健康度预警暂不是安全网**：台账判读门槛已改为独立 signal_date 簇数（≥8），
  实测四组分别只有 2~3 个交易日，全部输出「无法推断」（旧实现数笔数，
  曾把 69 笔/3 天判成「✓ 正常」）。攒够前请勿依赖它
- **D 维（情绪 15 分）横截面区分度恒为 0**：情绪周期阶段同日恒定，给同日所有票
  加同一个常数，对排序无影响、只抬高绝对分。它只能做择时（仓位），不能做选股
- **史测期望分层可复算性（2026-09-15 更新）**：`slam_2board` 已可复算
  （`fills_v2.csv` 含 `lianban`/`is_slam` 列，verdict=unproven：n=22、
  −1.14%、t=−0.56，「仓位加倍」已关闭）。N字/十字星模式已于 2026-09-16 全量移除；
  `events.csv` 本轮已补 `lianban`/`vr`/`gap_event` 列，因子分层不再依赖不可复算快照。
  ⚠ `fills_v2` 的成交判定基于旧 `limit_price`（取整高估一分）——边界样本上
